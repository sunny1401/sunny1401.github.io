SSL4EO MultiProduct Collated Dataset

This dataset provides global 10K most populous locations from Sentinel1/2 and Landsat missions. The dataset was collated from SSL4EO-L and SSL4EO-S12. Apart from original metadata from the geotifs, it contains an additional context file which contains information extracted from filenames and geotif metadata for ease of access. Data has been preprocessed save Normalization for quick access when developing ML products.

ssl4eo-s12-landsat-combined: This dataset combines SSL4EO-L and SSL4EO-S12 to form a combined multiview dataset. The combined dataset has 66800 locations with view from at least 5 sensors. The sensors available are:

  • Sentinel-1
  • Sentinel-2
  • Landsat-5
  • Landsat-7
  • Landsat-8
